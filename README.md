# 🎯 ก่อนเข้าสัมภาษณ์


## จำให้ได้


### Project

- ทำอะไร
- ทำไมเลือก Technology นี้
- ตัวเองรับผิดชอบอะไร
- ปัญหาที่เจอ


### Technical

อย่าท่อง Definition อย่างเดียว

ให้ตอบ:

"Concept คืออะไร"

+

"ใน Project ใช้อย่างไร"


ตัวอย่าง:


Q: JWT คืออะไร?


ตอบ:

JWT เป็น Token สำหรับยืนยันตัวตนครับ

ใน Project ผมใช้หลังจาก Login สำเร็จ

Backend จะสร้าง Token และให้ Frontend ส่งกลับมาเมื่อเรียก API ที่ต้อง Authentication ครับ
