# 1. System Overview


## Q1. ช่วยอธิบายโปรเจกต์ ChatBot HomeyPets ให้ฟังหน่อย?


## 🗣️ แนวตอบ

ChatBot HomeyPets เป็นระบบ Chatbot สำหรับช่วยตอบคำถามเกี่ยวกับสัตว์เลี้ยงครับ

ผู้ใช้สามารถสอบถามเกี่ยวกับอาการ ปัญหาสุขภาพ หรือการดูแลสัตว์เลี้ยงได้

ระบบใช้ RAG ในการค้นหาข้อมูลจาก Knowledge Base แล้วนำข้อมูลมาให้ AI สร้างคำตอบครับ


---

## Q2. ระบบนี้แก้ปัญหาอะไร?


## 🗣️ แนวตอบ

ระบบช่วยให้ผู้ใช้เข้าถึงข้อมูลเกี่ยวกับสัตว์เลี้ยงได้ง่ายขึ้นครับ

ผู้ใช้ไม่จำเป็นต้องค้นหาข้อมูลจากหลายแหล่งด้วยตัวเอง

สามารถถามผ่าน Chatbot และได้รับคำตอบจากข้อมูลที่เตรียมไว้ครับ


---

## Q3. ทำไมไม่ใช้ ChatGPT อย่างเดียว?


## 🗣️ แนวตอบ

เพราะ ChatGPT เป็น AI ทั่วไปครับ

แต่ระบบนี้ต้องการให้ AI ตอบจากข้อมูลเฉพาะด้านสัตว์เลี้ยง

จึงใช้ RAG เพื่อเพิ่มข้อมูลเฉพาะของระบบ และช่วยลดโอกาสที่ AI จะตอบผิดครับ


---

## Q4. คุณรับผิดชอบส่วนไหน?


## 🗣️ แนวตอบ

ผมรับผิดชอบในส่วนการพัฒนาระบบ Chatbot ครับ

เช่น การเชื่อมต่อ Frontend กับ Backend

การพัฒนา API

และส่วนของ RAG Pipeline เช่น การเตรียมข้อมูลและเชื่อมต่อ AI Model ครับ


---

## 🗣️ แนวตอบ

ระบบแบ่งเป็นหลายส่วนครับ

Frontend ใช้ React สำหรับรับคำถามจาก User

Backend ทำหน้าที่รับ Request และจัดการ Logic

RAG System ทำหน้าที่ค้นหาข้อมูลที่เกี่ยวข้องจาก Vector Database

จากนั้นส่งข้อมูลให้ LLM สร้างคำตอบกลับมาให้ User ครับ

---

## Q6. Data Flow ทำงานอย่างไร?

## 🗣️ แนวตอบ

เมื่อ User ส่งคำถามเข้ามา

ระบบจะนำคำถามไปทำ Embedding

จากนั้นค้นหาข้อมูลที่มีความใกล้เคียงใน Vector Database

แล้วนำข้อมูลที่ค้นหาได้ไปรวมกับ Prompt ส่งให้ LLM สร้างคำตอบครับ

---

# 3. RAG (Retrieval Augmented Generation)

## Q7. RAG คืออะไร?

## 📌 จำ

Search + Generate

## 🗣️ แนวตอบ

RAG คือเทคนิคที่รวมการค้นหาข้อมูลกับการสร้างคำตอบของ AI ครับ

ก่อนให้ AI ตอบ ระบบจะค้นหาข้อมูลที่เกี่ยวข้องจาก Knowledge Base ก่อน

แล้วนำข้อมูลนั้นไปให้ LLM ใช้ประกอบการตอบครับ

---

## Q8. ทำไมต้องใช้ RAG?

## 🗣️ แนวตอบ

เพราะช่วยให้ AI ตอบโดยอ้างอิงจากข้อมูลเฉพาะของระบบครับ

ช่วยลดปัญหา AI สร้างข้อมูลที่ไม่มีอยู่จริง หรือ Hallucination ครับ

---

## Q9. RAG ต่างจาก Fine-tuning อย่างไร?

## 🗣️ แนวตอบ

RAG เป็นการเพิ่มข้อมูลตอน Query โดยไม่ต้อง Train Model ใหม่ครับ

ส่วน Fine-tuning คือการนำข้อมูลไปฝึก Model เพิ่ม

RAG เหมาะกับข้อมูลที่เปลี่ยนแปลงบ่อย เพราะสามารถอัปเดตข้อมูลได้ง่ายกว่า

---

# 4. Embedding

## Q10. Embedding คืออะไร?

## 🗣️ แนวตอบ

Embedding คือการแปลงข้อความให้กลายเป็นตัวเลข Vector ครับ

เพื่อให้ระบบสามารถเปรียบเทียบความหมายของข้อความและค้นหาข้อมูลที่ใกล้เคียงกันได้

---

## Q11. ทำไมต้องแปลงข้อความเป็น Vector?

## 🗣️ แนวตอบ

เพราะ Computer ไม่เข้าใจความหมายของข้อความโดยตรงครับ

Vector ทำให้ระบบสามารถคำนวณความคล้ายกันของข้อมูลได้

---

## Q12. Similarity Search คืออะไร?

## 🗣️ แนวตอบ

เป็นการค้นหาข้อมูลที่มีความหมายใกล้เคียงกับคำถามของ User ครับ

โดยเปรียบเทียบระยะห่างระหว่าง Vector เช่น Cosine Similarity

---

# 5. Vector Database

## Q13. Vector Database คืออะไร?

## 🗣️ แนวตอบ

Vector Database เป็นฐานข้อมูลที่ออกแบบมาสำหรับเก็บข้อมูลแบบ Vector ครับ

ใช้สำหรับค้นหาข้อมูลที่มีความหมายใกล้เคียงกันอย่างรวดเร็ว

---

## Q14. เก็บข้อมูลอะไรใน Vector Database?

## 🗣️ แนวตอบ

เก็บข้อมูลที่ผ่านการทำ Embedding แล้วครับ

เช่น

- ข้อมูลโรคสัตว์
- อาการ
- วิธีดูแล
- คำแนะนำต่าง ๆ

---

## Q15. ถ้าข้อมูลเพิ่มขึ้นมากจะทำอย่างไร?

## 🗣️ แนวตอบ

สามารถเพิ่มประสิทธิภาพด้วยการจัดการ Index ของ Vector Database

และปรับวิธีค้นหาให้เหมาะสมกับจำนวนข้อมูลครับ

---

## Q16. เตรียมข้อมูลก่อนใช้ AI อย่างไร?

## 🗣️ แนวตอบ

เพื่อให้ระบบค้นหาเฉพาะส่วนที่เกี่ยวข้องได้ง่ายขึ้น

---

## Q18. ทำไมต้องแบ่งข้อมูลเป็น Chunk?

## 🗣️ แนวตอบ

การแบ่ง Chunk ช่วยให้ค้นหาได้แม่นขึ้นและลดข้อมูลที่ไม่เกี่ยวข้อง
